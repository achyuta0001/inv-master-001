invoice-gen — database schema

Multi-tenant GST invoicing. Everything roots at companies. Fourteen tables, eighteen real foreign keys, and three soft references the app enforces but the database does not. Reverse-engineered from the Flyway migrations and JPA entities.

⚠ Three references have no database foreign key

These columns are plain bigints mapped as @Column (not @ManyToOne). Referential integrity lives only in application code — orphans are possible, and a JOIN won't be constraint-checked. Deleting a customer or product will not cascade or block here.

fromto

invoice_line_items.product_id⇢products.id
invoice_sequences.invoice_id⇢invoices.id
